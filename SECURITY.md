# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's advisory flow:

**[Report a vulnerability](https://github.com/Ex0danify/WebSpeak/security/advisories/new)**

Do not open a public issue, pull request, or discussion for a suspected vulnerability.

### What to include

- What the problem is and the impact you expect (for example information disclosure, bypassed authentication, remote code execution).
- The affected component: web app, gateway, or relay.
- The version, image digest, or commit you tested.
- Steps to reproduce, and a proof of concept if you have one.

Please remove passwords, tokens, and session cookies from anything you send.

## Supported versions

WebSpeak ships the gateway and web app together, and only the latest release is supported. Fixes land on `master` and go out in the next release; there are no backports to older versions.

## Disclosure

We aim to acknowledge a report within a few days and will keep you updated while we work on a fix. Once a fix is released we will publish an advisory and credit you, unless you prefer to stay anonymous.
